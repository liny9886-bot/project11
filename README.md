# 臺中公園光影漫遊影展專題 - Vibe Coding Prompt 說明文件

本專題為逢甲大學數位行銷程式設計基礎課程之期中實作。在開發過程中，透過與 AI 進行協作（Vibe Coding），系統化地完成網頁架構、版面配置、SEO 優化與 RWD 響應式設計。以下為各階段核心使用的 Prompt 紀錄與設計邏輯：

## 一、 核心架構與版面設計 Prompt
* **設計目標**：建立具有上方導覽列（Header）、固定側邊欄（Sidebar）與主要內容區（Main）的完整分頁網頁，並採用 CSS Grid 系統。
* **使用的 Prompt 指令**：
  > 「請協助建立一個大二影展專題網站（主題：臺中公園光影漫遊），使用 CSS Grid 系統（`grid-template-areas`）建構出具備頂部導覽列、側邊欄與主內容區的網格版面。主色系請採用柔和的粉色系（Rose / Soft Pink），並確保首頁、節目表分頁與關於分頁的架構一致。」

## 二、 CSS 檔案切割與資料夾結構 Prompt
* **設計目標**：將樣式依功能模組化，並存放於指定的 `css/` 檔案匣中。
* **使用的 Prompt 指令**：
  > 「請將 CSS 樣式嚴格進行檔案切割：
  > 1. `style.css`：放置全站 CSS 變數（粉色系主題色系）、字型與通用基礎設定。
  > 2. `layout.css`：放置網格系統（Grid System）、導覽列與側邊欄的排版規則。
  > 3. `rwd.css`：放置螢幕寬度在 768px 以下的媒體查詢（Media Query），確保手機等手持裝置能完整顯示側邊欄與選單內容。」

## 三、 SEO 與 RWD 完整性 Prompt
* **設計目標**：符合搜尋引擎優化（SEO）規範，並在行動裝置上具備極佳的可用性。
* **使用的 Prompt 指令**：
  > 「請為專題首頁 (`index.html`) 加入完整的 HTML5 語意標籤與 Meta SEO 最佳化標籤（包含 `<title>`, `<meta name=\"description\">`, `<meta name=\"keywords\">`），並確保透過手機瀏覽時，側邊欄會自動轉換為橫向可滑動選單，版面不跑版。」
